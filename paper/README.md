# paper/

Everything for writing the conference paper about this project. The code and its own documentation live elsewhere in the repository; this folder only holds paper material.

| File | What it is |
|---|---|
| `PAPER_STATE.md` | Current status: venue, each section's state, final evaluation numbers, decisions, open questions, next step. Read this first. |
| `PAPER_CHAT_PROMPT.md` | The prompt to paste into a new Claude chat to carry on the paper work |
| `Master_Plan.docx` | The complete description of the project, its evidence, limitations and what the paper may claim. Same content as `docs/MASTER_PLAN.md` |
| `Source_Table.docx` | Every reference, verified, with its full citation and what the paper uses it for |
| `Literature_Notes.docx` | What the closest papers actually do, how this work differs, and the sentences the paper will use |
| `Abstract.pdf` | The abstract submitted to BAICONF 2026 |
| `applied-scripts/` | `fix-rules.sh` and `eval-setup.sh`, kept for the record. Both are already applied; do not run them again |

Related material elsewhere:

- `eval/`: the evaluation (questions, answer key, runner, marking rules) and `eval/results/` (every answer, `summary.md`, `answers.csv`, the guard stress test)
- `docs/MASTER_PLAN.md`: the master plan in Markdown, with its two diagrams

Venue: BAICONF 2026, IIM Bangalore, 17 to 19 December 2026. Full paper due 31 October 2026.
